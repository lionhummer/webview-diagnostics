# Changelog

## 0.1.0 — 2026-10-11

Initial public release: portable SQLite journal, bounded summary/detail retention, explicit capture ownership, page-scoped queries, credential-field redaction, stream summaries, and optional macOS WebKit capture with capability reporting.

Includes journal/correlation regression tests and a real WKWebView/loopback HTTP smoke example. Native capture is experimental and uses private WebKit selectors.
